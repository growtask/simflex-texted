Документация

Дерево страниц — на стороне CMS. Ted отвечает за страницу: просмотр ↔ правка без перезагрузки; двойной клик по тексту тоже открывает правку. Каждая страница сохраняется отдельно (localStorage). Переключатель «Доступ» показывает режим только чтения (`readOnly: true`): правки нет, кнопки «Редактировать» нет — так выдают доступ без редактирования.
