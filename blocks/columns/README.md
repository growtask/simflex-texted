# Блок «Колонки» (`columns`)

Две–четыре колонки, в каждой — обычные блоки (картинка, заголовок, текст…); на планшете не больше двух в ряд, на телефоне — одна под другой. Макет `block-columns`. Блок целиком в этой папке: ядро его не упоминает (тест набора `blocks`).

## Как ядро с ним работает

Колонки — контейнер (`container: true` в `block.json`): колонки — «хосты» обычных блоков; общий код контейнеров (`resources/js/core/containers.js`) узнаёт его по реестру. Остальное — через точки реестра (`columns.js` → `registerBlock`):

| Точка | Что делает |
|---|---|
| `create` | две колонки: пустое изображение (`blockDef('image').blank`), «Заголовок», текст; курсор в заголовке |
| `editorUi` (`editor.columns`) | «Добавить колонку», клавиши на краях колонок — `columns.editor.js`; `itemAt`, `ownsItem`, `itemAbove: 'card'`, `canRemove`, `itemRemoved`, `itemCaret`, `removedToast` — кнопки над правым верхним углом, не меньше двух колонок, класс числа колонок, курсор после удаления |
| `clean`, `serialize`, `normalize` | 2–4 колонки, класс их числа, тело — как корень; без колонок — абзац |
| `unnest` | колонки в теле другого контейнера — блоки подряд |
| `placeholders` | «Заголовок», «Текст колонки» |
| `toText` (+ `columns.php`) | в наборе без колонок — блоки колонок подряд |
| `canAlign`, `canBg` | без выравнивания и фона |
| `inContainers: false` | не вставляется в другие контейнеры |

Ритм блоков в колонке на сайте (`.ted-columns__col > *`) — общее правило `resources/css/content.css` для всех «хостов».

## Файлы

| Файл | Что внутри |
|---|---|
| `block.json` | описание, меню и образец плитки, контейнер |
| `columns.js` | разметка, очистка, нормализация, сохранение, раскрытие, регистрация (бывш. часть `resources/js/core/containers.js`) |
| `columns.editor.js` | правка: «Добавить колонку», клавиши |
| `columns.php` | превращение в текст на сервере |
| `columns.site.css`, `columns.editor.css` | вид на сайте и в редакторе; отличия в редакторе |
| `columns.test.js` | тесты блока (набор `blocks`) |
