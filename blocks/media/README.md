# Медиа (`media`: `image`, `gallery`, `video`, `audio`, `file`)

Изображение, галерея, видео, аудио и файл по макетам Media/*: фигура с подписью (text/t3), галерея сеткой, видео 16:9 с плеером площадки, аудиоплеер Media/audio (один и тот же в редакторе и на сайте), карточки файлов.

## Разметка

`<figure class="ted-media ted-media--image"><img …><figcaption>…</figcaption></figure>`; галерея — фигуры внутри фигуры; видео — ссылка `data-ted-video`; аудио — `<audio>`; файл — ссылки `download`.

## Как ядро с ним работает

Семейство целиком в этой папке: ядро не упоминает ни виды, ни их классы (тест набора `blocks`). В редакторе блок живёт в обёртке правки `<div class="ted-ui-media" contenteditable="false">` с панелью загрузки; обёртку объявляет `block.json → wrap`, ядро узнаёт её через `isWrap` / `wrapSelector` (выделение, история, ручки, клавиши, вставка).

| Точка | Что делает |
|---|---|
| `insert` | вставка из «/», «Все блоки» и «Медиа ▾» — пустой блок с выбором файла |
| `insertMenu` (block.json) | пункты «Медиа ▾» на панели: изображение, видео, аудио, файл |
| `menu.picker` (block.json) | «Файл» в «Все блоки» — в своей группе «Файлы» |
| `editorUi` (`editor.media`) | загрузка, окна, плитки галереи, плеер — `media.editor.js`; ещё `refresh`, `onKey` (Alt+Enter — настройки), `statsOf` (сводка), `pasteFiles`, `pasteLink` («как показать ссылку»), `afterPaste` (чужие картинки — на свой сервер) |
| `clean`, `serialize` (с обёрткой) | очистка, сохранение — блок внутри обёртки, якорь — с обёртки |
| `fromRaw` | вставленная со страницы одиночная картинка — «Изображение» |
| `blank` | пустое изображение (колонки) |
| `filesOf` | свои файлы в HTML — после сохранения лишние удаляются с сервера |
| `toText` (+ `media.php`), `degrade: drop` | в наборе без вида: файл и видео — ссылками, остальное исчезает |

Загрузка на сервер (`src/core/upload.js`, `server.js`) и уборка неиспользованных файлов после сохранения — общие службы ядра: адреса файлов им даёт блок.

## Файлы

| Файл | Что внутри |
|---|---|
| `block.json` | семейство из пяти видов, меню, обёртка правки |
| `media.js` | адреса, разметка, разбор, очистка, сохранение, JSON, регистрация |
| `media.editor.js` | загрузка, окна (адрес, подпись, замена), плитки галереи и перетаскивание, вставка файлов и ссылок |
| `audio-player.js`, `file-names.js`, `video-link.js` | плеер, названия файлов, кнопка «Смотреть на …» — общие для редактора и сайта |
| `media.php` | превращение в текст на сервере |
| `media.site.css`, `media.editor.css` | вид на сайте; правка в редакторе (бывш. `styles/ui/media.css`) |
| `media.site.js` | на сайте: плеер, названия файлов, видео площадок |
| `media.test.js` | тесты медиа (набор `blocks`) |
