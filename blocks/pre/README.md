## Разметка

`<pre data-lang="js" data-nums="1\n2"><code>…</code></pre>` — внутри всегда `<code>`; в сохранённом HTML — токены подсветки `<span class="ted-tok-…">`. Номера строк включены по умолчанию, выключенные — `data-nonums`.

## В редакторе

Текстовый блок: ввод, Enter, вставку, подсветку в правке, шапку с выбором языка и копированием ведёт текстовый движок ядра (`src/core/editor.js`, `src/ui/handle.js`, `src/core/highlight.js`). Отсюда — меню «Текст → Код», «Стиль текста → Код», Markdown «```» + Enter, другое имя в наборах `code`, JSON `{ "type": "code", "lang", "code" }`, стили и кнопка «Копировать код» на сайте. В наборе без кода блок становится абзацем с переносами строк — и в браузере, и на сервере.
