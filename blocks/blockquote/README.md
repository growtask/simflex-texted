# Блок «Цитата» (`blockquote`)

Цитата (макет `block-quote`, Text/quote): линия 3 px main/color1/main, отступ 20, текст t1 (20 / 1.5) цвета text-icon/gray/darker. С автором (`type=author`): аватар 40 с инициалами, имя 16 / 600, должность 11.

| Меню | «Текст», значок `quote`, «Превратить в…»: да |
| Блок без текста | нет |
| Горячая клавиша | `Mod+Shift+9` |
| Белый список | `blockquote`, `p` (data-initials, data-author-id) |
| В наборе без блока | становится текстом |

## Разметка

```html
<blockquote>
  <p>Текст цитаты</p>
  <p class="ted-author" data-initials="АП"><strong>Анна Петрова</strong><br>Редактор</p>
</blockquote>
```

Автор — необязательный последний абзац `p.ted-author`: имя жирным, должность после `<br>`, инициалы для аватара в `data-initials` (собираются из имени), `data-author-id` — id автора в CMS.

## В редакторе

Текстовый блок (правку ведёт текстовый движок ядра): «> » в начале строки, `Ctrl+Shift+9`, меню «/» и «Стиль текста». Пока курсор в цитате без автора, под ней кнопка «+ Добавить автора»; заглушки «Имя» и «Должность». В наборе без цитаты (`text`) — абзацы, автор не переносится.
