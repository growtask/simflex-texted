# Блок «Заголовок» (`h2`–`h6`)

Заголовки разделов (макет `block-heading`, Text/heading): шрифт заголовков, 700, высота строки 1, цвет text-icon/gray/darker. Размеры: десктоп 42 / 28 / 24 / 20 / 16, до 811 px — 28 / 24 / 20 / 20 / 16. Семейство: одна папка, пять видов (`variants` в `block.json`).

## Разметка

`<h2>`…`<h6>`, необязательно `id` (якорь — ссылка на раздел), классы выравнивания и цветного фона.

## В редакторе

Текстовый блок (правку ведёт текстовый движок ядра). В меню «/» — h2, h3, h4; в «Стиле текста» — все пять; `Ctrl+Shift+2…6`; Markdown «## » … «###### » в начале строки. Подсказка пустого заголовка — «Заголовок». В наборах без заголовков (`text`) заголовок становится абзацем.

## Файлы

| Файл | Что внутри |

| `heading.site.css` | вид на сайте (и в редакторе) |
| `heading.test.js` | тесты блока (набор `blocks`) |
