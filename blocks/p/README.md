## Разметка

`<p>` со строчным оформлением (жирный, курсив, подчёркнутый, зачёркнутый, код, метка, ссылка, индексы). Необязательные классы: выравнивание `ted-align-center` / `ted-align-right`, цветной фон `ted-bg-gray` / `ted-bg-color1` / `ted-bg-color2` (блок «Цветной фон»).

## В редакторе

Текстовый блок: ввод, Enter (новый абзац), Backspace (склейка), Markdown в начале строки («# », «- », «1. », «> », «[] », «---», «```») и превращение в другие текстовые блоки ведёт текстовый движок ядра — он общий для абзаца, заголовков, цитаты, кода и списков. Здесь — описание блока: место в меню «/» и «Стиль текста», `Ctrl+Shift+0`, подсказка пустого абзаца, JSON и стили. Абзац есть в любом наборе.
