`<ul class="ted-proscons"><li class="ted-pros"><strong>Плюсы</strong><ul><li>…</li></ul></li><li class="ted-cons"><strong>Минусы</strong><ul><li>…</li></ul></li></ul>`

## В редакторе

Текстовый блок: ввод, Enter, Backspace, заглушки и кнопки внутри блока ведёт текстовый движок ядра (`src/core/editor.js`, `src/core/blocks.js`, стили правки — `styles/ui/blocks.css`); превращение в текст в наборе без блока — `src/core/blocks.js` и `src/Presets.php` (одинаково). Отсюда — плитка «Акцент → Плюсы и минусы», новый блок (по три пустых пункта), JSON, стили на сайте.
