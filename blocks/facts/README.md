## В редакторе

Текстовый блок: ввод, Enter, Backspace, заглушки и кнопки внутри блока ведёт текстовый движок ядра (`src/core/editor.js`, `src/core/blocks.js`, стили правки — `styles/ui/blocks.css`); превращение в текст в наборе без блока — `src/core/blocks.js` и `src/Presets.php` (одинаково). Отсюда — плитка «Акцент → Ключевые цифры», новый блок (две пустые плитки), JSON, стили на сайте.
