# Блок «Встраивание» (`embed`)

Карточка-снимок статьи CMS или страницы по ссылке (OpenGraph — страницу читает сервер CMS), полная или в одну строку. Макет `block-embed (Embed/embed type=post)`, окно `editor-popover kind=embed`. Блок целиком в этой папке: ядро его не упоминает (тест набора `blocks`).

## Разметка

`<div class="ted-embed [ted-embed--compact]" [data-ted-article="id"]>` — шапка (аватар, заголовок, строка «сайт · дата»), текст, картинка, низ (просмотры, лайки, «Открыть»). Полностью — в комментарии `embed.js`.

## Безопасность

Атрибут `data-ted-article` (id статьи CMS) — в белом списке через `html` в `block.json`; поле `ids` включает правило «значение — id CMS» (JS и PHP одинаково). Ссылки и картинки — только через `urlOk`.

## Как ядро с ним работает

Только через реестр (`embed.js` → `registerBlock`):

| Точка | Что делает |
|---|---|
| `create`, `afterInsert` | пустой блок с полем ссылки и «Добавить», курсор — в поле |
| `editorUi` (`editor.embeds`) | поле ссылки, поиск статей CMS, окно «Настройки встраивания» — `embed.editor.js` |
| `clean`, `serialize`, `normalize` | очистка (пустой блок не сохраняется), сохранение, пересборка карточки из данных |
| `toText` (+ `embed.php` → `degrade`) | в наборе без встраивания — ссылка с заголовком карточки |
| `fromLink`, `canFromLink` | вставили ссылку отдельным абзацем — «Встроить карточкой» (если CMS подключила `opengraph`) |
| `canAlign`, `canBg` | выравнивания и цветного фона нет |
| `neverEmpty`, `caretBelow` (block.json) | не пустая строка; под ним строка для курсора |

| Файл | Что внутри |
|---|---|

| `embed.php` | превращение в текст на сервере |
| `embed.site.css`, `embed.editor.css` | вид на сайте и в редакторе; отличия в редакторе |
| `embed.test.js` | тесты блока (набор `blocks`) |
