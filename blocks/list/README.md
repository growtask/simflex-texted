# Блок «Список» и «Нумерованный список» (`list`: `ul`, `ol`)

Списки текста (Text/body, type list / list-numb): отступ слева, маркеры по уровню вложенности, цвет маркера, зазор между пунктами.

## Разметка

`<ul><li>…</li></ul>`, `<ol start="3" reversed type="a"><li>…</li></ol>`; вложенный список — внутри пункта.

## В редакторе

Текстовый блок: пункты, Enter, Tab / Shift+Tab (вложенность), Markdown «- », «* », «1. » ведёт текстовый движок ядра. Отсюда — плитки «Списки → Список / Нумерованный список», «Стиль текста», Ctrl+Shift+8 / 7, белый список, JSON `{ "type": "ul", "items": [...] }`, стили. Чек-лист, шаги, ключевые цифры, плюсы и минусы — тоже `ul` / `ol`, но отдельные блоки: `selector` их исключает. В наборе без списков пункты становятся абзацами — и в браузере, и на сервере.
