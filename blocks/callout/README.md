# Блок «Выноска» (`callout`)

Заметка на плашке (макет `block-callout`): плашка r16 цвета main/gray/lighter (тёмная — main/gray/darker), значок «информация» 24, заголовок 16 / 700, текст 13 / 1.5. «Цветной фон» перекрашивает плашку.

| Поле | Значение |

| Вид | `callout` |
| Название | Выноска |
| Меню | «Акцент», значок `callout`, «Превратить в…»: да |
| Блок без текста | нет |
| Белый список | `blockquote` |
| В наборе без блока | остаются вложенные абзацы |
| Макет Figma | block-callout |

## Разметка

```html
<blockquote class="ted-callout"><p><strong>Заголовок</strong></p><p>Текст</p></blockquote>
```

## В редакторе

Вставка — меню «/» или «Все блоки» → «Акцент» → «Выноска»: курсор в заголовке, заглушки «Заголовок выноски» и «Текст выноски». Enter в заголовке переходит в текст, Enter в пустом последнем абзаце выходит из выноски. Абзацы внутри ведёт текстовый движок ядра. Delete в конце абзаца перед выноской не втягивает её текст (`compound`). В наборе без выноски остаются её абзацы (`degrade: children` — так же на сервере).
