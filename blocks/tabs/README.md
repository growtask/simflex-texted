# Блок «Вкладки» (`tabs`)

Разделы под рядом названий; внутри вкладки — обычные блоки. На сайте без скрипта — разделы подряд с заголовками, с `content.js` — ряд вкладок. Макет `block-tabs (Tabs/main underline m)`. Блок целиком в этой папке: ядро его не упоминает (тест набора `blocks`).

## Как ядро с ним работает

Вкладки — контейнер (`container: true` в `block.json`): тела вкладок — «хосты» обычных блоков; общий код контейнеров (`resources/js/core/containers.js`: хост, цветной фон и вложенные контейнеры в теле) узнаёт его по реестру. Остальное — через точки реестра (`tabs.js` → `registerBlock`):

| Точка | Что делает |
|---|---|
| `create` | три вкладки, курсор в названии первой |
| `editorUi` (`editor.tabs`) | активная вкладка, «Добавить вкладку», клавиши — `tabs.editor.js`; `itemAt`, `ownsItem`, `itemAbove`, `itemRemoved`, `blockOfItems`, `removedToast` — кнопки ⠿ 🗑 над названием, удаление вкладки с содержимым, последней — с блоком |
| `clean`, `serialize`, `normalize` | панели сайта ↔ форма правки; без названий — абзац |
| `unnest` | вкладки в теле другого контейнера — названия жирным и содержимое |
| `placeholders` | «Вкладка» в пустом названии |
| `toText` (+ `tabs.php`) | в наборе без вкладок — название жирным, за ним блоки |
| `canAlign`, `canBg`, `toolbar` | без выравнивания, фона и стиля текста в названии |
| `inContainers: false` | не вставляется в другие контейнеры |

Ритм блоков внутри панели на сайте (`.ted-tabs__panel > *`) — общее правило `resources/css/content.css` для всех «хостов» (корень статьи, ответ аккордеона, колонка).

## Файлы

| Файл | Что внутри |
|---|---|
| `block.json` | описание, меню и образец плитки, правила панели, контейнер |
| `tabs.js` | разметка, очистка, нормализация, сохранение, раскрытие, регистрация (бывш. часть `resources/js/core/containers.js`) |
| `tabs.editor.js` | правка: активная вкладка, «Добавить вкладку», клавиши |
| `tabs.php` | превращение в текст на сервере |
| `tabs.site.css`, `tabs.editor.css` | вид на сайте и в редакторе; отличия в редакторе |
| `tabs.site.js` | ряд вкладок на сайте (в `content.js`) |
| `tabs.test.js` | тесты блока (набор `blocks`) |
