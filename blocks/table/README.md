# Блок «Таблица» (`table`)

Таблица до 10 столбцов и 100 строк: шапка, границы, подпись, формулы в ячейках, вставка из Excel и Google Таблиц; на сайте — прокрутка по ширине. Макет `block-table (Table/table)`. Блок целиком в этой папке: ядро его не упоминает (тест набора `blocks`).

## Как ядро с ним работает

Только через реестр (`table.js` → `registerBlock`):

| Точка | Что делает |
|---|---|
| `create` | таблица 3 × 3 с шапкой, курсор в первой ячейке |
| `adopt`, `clean` | простая чужая `<table>` — тоже блок; сложная (объединённые ячейки, больше 10 столбцов) — `clean` → `false`: остаётся «сырым» HTML |
| `normalize` | порядок формы правки; таблицу удалили целиком — на её месте абзац |
| `editorUi` (`editor.table`) | кнопки строк и столбцов, «Добавить строку / столбец», перетаскивание, формулы — `table.editor.js`, `table-formula.js`; `syncFirst` / `afterSync` (до и после кнопок блока), `onKeyFirst` (Enter, Tab, стрелки в ячейках), `onPaste` (из Excel), `lockStyle` (в ячейке нет стиля блока и выравнивания) |
| `blockMenu` | меню блока: «Добавить / Убрать шапку», «Убрать / Показать границы» |
| `placeholders` | «Заголовок», «Текст», «Описание» |
| `toText` (+ `table.php`) | в наборе без таблицы — строки абзацами, ячейки через « · », подпись |
| `canAlign`, `canBg`, `toolbar` | без выравнивания, фона и стиля текста; форматирование текста — есть |
| `compound`, `neverEmpty`, `lineAfter` (block.json) | Delete в конце абзаца перед таблицей не втягивает её текст; не пустая строка; под ней строка текста |

Общие правила, не упоминания блока: HTML-теги таблицы и значения атрибутов `data-cols` (1–10) и `data-formula` (знаки формул) — в общем белом списке (`resources/js/core/allowlist.js` = `Sanitizer`, правила безопасности не менялись); общие кнопки «Добавить …» и правила их скрытия при перетаскивании в `resources/css/ui/blocks.css` называют и строку «Добавить строку / столбец».

## Файлы

| Файл | Что внутри |
|---|---|
| `block.json` | описание, меню и образец плитки, правила панели |
| `table.js` | разметка, очистка, строки и столбцы, шапка, границы, вставка из Excel, меню блока, регистрация (бывш. `resources/js/core/table.js`) |
| `formula.js` | формулы: разбор, вычисление, сдвиг ссылок (бывш. `resources/js/core/formula.js`) |
| `table.editor.js`, `table-formula.js` | правка таблицы и формул (бывш. `resources/js/ui/table.js`, `resources/js/ui/table-formula.js`) |
| `table.php` | превращение в текст на сервере |
| `table.site.css`, `table.editor.css` | вид на сайте и в редакторе; отличия в редакторе |
| `table.site.js` | прокрутка таблицы на сайте (в `content.js`) |
| `table.test.js`, `formula.test.js` | тесты блока и формул (набор `blocks`) |
