# Блок «Содержание» (`toc`)

Оглавление статьи: заголовок, главы — ссылки на якоря страницы, на сайте — полоса прочтения и «Скрыть». Макет `block-navigation`, окно `editor-popover kind=chapter`. Блок целиком в этой папке: ядро его не упоминает (тест набора `blocks`).

## Как ядро с ним работает

Только через реестр (`toc.js` → `registerBlock`):

| Точка | Что делает |
|---|---|
| `create` | пустое содержание, курсор — в заголовке; «Добавить главу» под блоком |
| `editorUi` (`editor.toc`) | окно «Глава содержания», «Добавить главу», «Скрыть», клавиши заголовка — `toc.editor.js`; `selectedItem`, `ownsItem`, `itemInside`, `afterItemRemove` — кнопки ⠿ 🗑 у главы внутри строки, блок остаётся и без глав |
| `clean`, `serialize`, `normalize` | `<nav>` на сайте, `<div>` в правке; главы — только ссылки на якоря |
| `placeholders` | «Заголовок» в пустом заголовке |
| `toText` (+ `toc.php`) | в наборе без содержания — заголовок жирным и список ссылок |
| `canAlign`, `canBg`, `toolbar` | без выравнивания, фона, стиля и форматирования |
| `inContainers: false`, `neverEmpty`, `lineAfter` (block.json) | не вставляется в аккордеон, вкладки, колонки; не пустая строка; последним — под ним строка текста |

## Файлы

| Файл | Что внутри |
|---|---|
| `block.json` | описание, меню и образец плитки, правила панели |
| `toc.js` | разметка, очистка, сохранение, якоря страницы, регистрация |
| `toc.editor.js` | правка: окно главы, «Добавить главу», «Скрыть» |
| `toc.php` | превращение в текст на сервере |
| `toc.site.css`, `toc.editor.css` | вид на сайте и в редакторе; отличия в редакторе |
| `toc.site.js` | полоса прочтения и «Скрыть» на сайте (в `content.js`) |
| `toc.test.js` | тесты блока (набор `blocks`) |
