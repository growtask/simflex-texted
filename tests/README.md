# Автотесты Ted

Тесты на чистом JS: без Node.js, без npm, без внешних библиотек. Раннер (`harness.js`) — около 60 строк. Запускаются в браузере, на исходниках из `src/`.

## Запуск

Без участия человека — `php bin/test.php`: сборка `dist/`, свой сервер `php -S`, наборы `tests/run.html` в браузере без окна
(Chrome, Chromium или Edge; путь можно задать в `TED_BROWSER`) и PHP-проверки `tests/php/`. Код выхода 0 — всё прошло.

| Команда | Что делает |
|---------|------------|
| `php bin/test.php` | все наборы по порядку: layer → drag → rhythm → server → presets → security → styles → blocks, затем PHP |
| `php bin/test.php --full` | то же + `dist/` в git = сборка из исходников и загрузка файлов на демо-сервере (`tests/php/test-upload.php`) |
| `php bin/test.php --suite=layer` | один набор (несколько — через запятую; `config` — только PHP-проверка настроек) |
| `php bin/test.php --only="слово"` | только тесты, в названии которых есть слово (без PHP-проверок) |

В браузере: `php -S 127.0.0.1:8140 -t . bin/serve.php` и `http://127.0.0.1:8140/tests/run.html?suite=layer` (после
`php bin/build.php` — страницы берут `dist/ted.css`).

| Параметр адреса | Что делает |
|-----------------|------------|
| `?suite=blocks` | набор (список — в `tests/run.html`) |
| `?only=тостеры` | выполнить только тесты, в названии которых есть слово |
| `?keep` | не убирать редакторы после прогона (посмотреть, что получилось) |

Для автоматического запуска: дождаться `window.__tedTests` — объект `{ total, failed: [{ name, error }] }`.

## Как писать тест

```js
import { group, test, eq, ok, wait } from './harness.js';

group('Моя область', () => {
  test('что проверяем', async () => {
    eq(1 + 1, 2);                 // строгое равенство, понятное сообщение при ошибке
    ok(условие, 'что не так');    // условие истинно
    await wait(400);              // подождать таймер редактора
  });
});
```

Помощники: `eq`, `deepEq`, `ok`, `wait`, `vis` (неразрывные пробелы показывает как «·»). В `helpers.js` — `make(html, options, { width, theme })` (новый редактор нужной ширины и темы), `select(ed, блок, от, до)`, `selectText(ed, 'слово')`, `typeText('...')` (настоящий ввод через `execCommand`), `pressEnter(ed)`, `pop(ed)` (окно этого редактора), `html(ed)`, `tagOf(ed, i)`.

Новый файл: `что-то.test.js` и строка `import './что-то.test.js';` в файле набора (`*.suite.js`, список наборов — `tests/run.html`).
Тесты блока — `blocks/<тип>/<тип>.test.js` (набор `blocks` подключает их по `bin/build.json`).

## Правила, о которые легко споткнуться

- **Окна редактора ищите через `pop(ed)`**, а не через `document.querySelector('.ted-ui-pop')`: окна прошлых тестов могут остаться в странице. `make()` их убирает, но привычка спасает от ложных ошибок.
- **`getInnerHTML()` не отдаёт пустые блоки.** Пустой заголовок после «# » проверяйте через DOM (`tagOf(ed)`), а не через HTML.
- **Таймеры.** `onChange` и черновик срабатывают через 250 мс после правки: ждите 400 мс.
- **`onSave` вызывается, только если текст изменился** (при сохранении без правок редактор просто уходит в просмотр).
- **Настройки браузера.** Выключенные категории ✨ запоминаются в `localStorage` (`ted-typograf-off`). `make()` сбрасывает ключ, но в своём тесте не полагайтесь на его состояние.
- **Типографика уже набранного текста.** Строка вроде «Всё хорошо» не считается «уже в порядке»: после слова до трёх букв стоит неразрывный пробел. Для проверки «ничего не менять» берите текст с `&nbsp;`.

## Размеры и темы

Тесты `sizes.test.js` создают редактор в обёртке нужной ширины (`make(html, options, { width: 414, theme: 'dark' })`): колонка, сетка плиток и мобильная шапка меню зависят от ширины контейнера (`@container ted`), а не окна браузера, поэтому проверяются в одном окне. Ожидаемые значения: колонка 700 / 628 / 480 / 382, плиток в ряд 3 / 3 / 2 / 2. Размеры слоя анимации (масштаб при появлении окна) измеряйте через `offsetWidth` / `offsetHeight`, а не `getBoundingClientRect`.

## Обход всех блоков (визуальный)

`tests/walkthrough.html` — живой редактор: каждый блок добавлен через меню «Все блоки», наполнен (набор текста, Enter, Tab, Ctrl+Enter) и пройден доступными кнопками панели (жирный, курсив, подчёркнутый, зачёркнутый, код, ссылка, якорь, выравнивание, цветной фон, стиль текста, ✨). Перед каждым результатом — подпись `h6`. Автопроверки после каждого шага: нет горизонтальной прокрутки, нет блоков за колонкой, в сохранённом HTML нет служебных атрибутов и нулевых пробелов, повторная очистка не меняет HTML, нет ошибок скрипта. Справа внизу — сводка. `?dark` — тёмная тема. Ширину проверяют окном браузера (1000 / 860 / 768 / 414): медиазапросы содержимого зависят от окна, поэтому автотесты в окне 1200 их не проверяют — только эта страница. Адрес: `http://localhost:8140/tests/walkthrough.html` (через `bin/serve.php`).

## Прямая загрузка по HTTP

`php bin/test.php --full` (или отдельно `php tests/php/test-upload.php`) поднимает демо-сервер (`bin/demo/media-demo.php`)
с папкой файлов и настройками во временной папке и проверяет: PNG → WebP, видео, аудио, файлы и GIF как есть, отдачу
частями (Range), удаление после сохранения без CMS, одинаковые названия, картинку по ссылке (не во внутреннюю сеть),
«двойной» GIF, конвертацию в WebM и постер (если есть ffmpeg: `TED_FFMPEG` или PATH), право на правку и набор поля.
Нужен PHP 8.4+ с `gd` (WebP) и `fileinfo`; PHP без php.ini — расширения подключаются из папки `ext` рядом с php.

Сквозная проверка руками — демо: `php bin/demo.php`.
