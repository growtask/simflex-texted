# Перенос статей, Markdown, нейросети, печать, язык

[← К оглавлению](README.md)

## Меню «Ещё ⋯»

| Пункт | Что делает |
|---|---|
| Скопировать промт | Промт для нейросети: как вернуть статью, чтобы редактор её принял (Markdown или JSON). Примеры блоков берутся из `block.json → jsonExample`. |
| Загрузить .md или .json | Заменяет статью файлом (формат — по расширению или содержимому). Перед заменой — предупреждение; «Отменить» в уведомлении или Ctrl+Z возвращают прежнюю. Неизвестные блоки JSON называются в уведомлении. |
| Выгрузить в Markdown | Статья файлом `.md`. Блоки без прямого аналога (аккордеон, вкладки, шаги…) — понятным текстом. |
| Выгрузить в JSON | Статья списком блоков: простой текст — `{ "type", "text" }`, остальное — `{ "type": "html", "html" }` без потерь. |
| Печать и PDF | Окно печати браузера: A4, поля, блоки не рвутся между страницами, аккордеон раскрыт. Для PDF выберите «Сохранить как PDF» (принтер «Microsoft Print to PDF» пишет файл, который не открывают некоторые просмотрщики). |
| English / Русский | Язык интерфейса редактора (статья не переводится), выбор запоминается в браузере. |

Вставленный обычным текстом Markdown (ответ нейросети, заметки) сразу становится блоками.

## Markdown

`Ted.fromMarkdown(md, { blocks })` → чистый HTML; `Ted.toMarkdown(html)` → Markdown.

| Markdown | Блок |
|---|---|
| `# Заголовок` / `## …` / `### …` | заголовок 2 / 3 / 4 (как сокращения «# » в редакторе) |
| `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `` `код` ``, `[ссылка](https://…)` | оформление в строке |
| `- пункт`, `1. пункт`, отступ — вложенность | списки |
| `- [ ] задача`, `- [x] готово` | чек-лист |
| `> текст` | цитата |
| `> [!NOTE] Заголовок` + строки `> текст` | выноска (также TIP, WARNING, IMPORTANT, CAUTION) |
| ` ```js … ``` ` | код с языком |
| `\| a \| b \|` + `\| --- \| --- \|` | таблица |
| `![описание](https://…)` | изображение |
| `---` | линия |

HTML внутри Markdown не выполняется: всё проходит обычную очистку (`Ted.clean` / `TedSanitizer::clean`).

## JSON

`Ted.toBlocks(html)` → список блоков; `Ted.fromBlocks(list, { blocks, skipped })` → HTML. Кроме блоков из `Ted.blockJsonTypes` (`p`, `h2`…`h6`, `ul`, `ol`, `checklist`, `quote`, `callout`, `steps`, `facts`, `proscons`, `code`, `image`, `gallery`, `video`, `audio`, `file`, `hr`) принимаются:

- `{ "type": "markdown", "text": "## Раздел\n\n- пункт" }` — кусок статьи в Markdown;
- `{ "type": "html", "html": "<figure class=\"ted-table\">…" }` — блок как есть (очищается).

Файл выгрузки: `{ "format": "texted-blocks", "version": 1, "blocks": [ … ] }`; загрузка принимает и просто массив.

## Старые статьи (TinyMCE)

Открываются как есть и превращаются в блоки: абзацы, заголовки, списки, цитаты, таблицы. Картинка внутри абзаца становится отдельным блоком «Изображение»; адреса от админки (`../../../uf/…`) и имена с пробелами и кириллицей приводятся к адресу от корня сайта. Проверено на 18 статьях: текст без потерь, все картинки на месте.

## Один документ в двух вкладках

Вкладки с тем же документом узнают друг о друге (BroadcastChannel): обе предупреждают, а сохранение после сохранения в другой вкладке сначала спрашивает подтверждение. Опция `presence: false` выключает.

## Язык интерфейса

`Ted.init({ lang: 'en' })` или «Ещё» → English; у открытого редактора — `ed.setLang('en')`. Свой язык: `Ted.addLang('de', { 'Русская строка': 'Übersetzung' })` — строки без перевода показываются по-русски. Словарь английского — `lang/en.js`.
