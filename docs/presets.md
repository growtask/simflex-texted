## Наборы блоков и право на правку

Набор (пресет) — какие блоки доступны в поле и как открывается редактор. **Набор поля и право пользователя на правку задаёт сервер CMS**, а не браузер: он передаёт их редактору и он же чистит сохранённый HTML по набору.

| Набор | Блоки | Как открывается | Где обычно |
|-------|-------|-----------------|------------|
| `full` | все | сразу правка | статьи, страницы, новости |
| `mini` | абзац, заголовки `h2`–`h4`, списки, цитата, изображение | сразу правка | анонсы, описания разделов |
| `text` | абзац и списки, **без заголовков** | сразу правка | описание товара, короткий текст, отзыв |
| `readonly` | все | только просмотр, правки нет | просмотр в админке |
| `docs` | все | просмотр на странице, «Редактировать» включает правку там же | раздел документации |

Строчное оформление (жирный, курсив, ссылки, якоря) есть во всех наборах.

```php
$ted = Config::load();
$canEdit = $user->canEdit($record);                                   // право решает CMS
// шаблон поля:
//   <script>Ted.init({ selector: '#content', server: <?= $ted->getClientJson('mini', $canEdit) ?> });</script>
// сохранение — очистка по набору; без права или в наборе readonly — отказ:
try { $clean = $ted->save($_POST['content'], 'mini', $canEdit); }
catch (AccessDenied $e) { http_response_code(403); exit; }
// загрузка файлов поля — тоже с проверкой права (без права — 403, на диск ничего не пишется):
$ted->respondToUpload($pagePath, 'mini', $canEdit);
```

- **Без права правки** (`canEdit` = `false`) в любом наборе: только просмотр, кнопки «Редактировать» нет, `Ctrl+Shift+P` и двойной клик правку не включают, `editor.setReadOnly(false)` её не возвращает. Скрытая кнопка — не защита сама по себе: сохранение и загрузку отклоняет сервер.
- **Запрещённый блок** (старый документ, вставка из буфера, подделанный запрос) **превращается в обычный текст**, а не пропадает: выноска → абзацы, цифры → «значение — подпись», шаги → нумерованный список, таблица → строки «ячейка · ячейка» и подпись, аккордеон и вкладки → заголовок жирным и их блоки, код → абзац. Так делают и редактор (при загрузке, вставке, сохранении), и сервер (`$ted->clean($html, $preset)`) — по одним правилам, их сверяет тест на общих примерах `tests/presets/vectors.json`.
- В редакторе запрещённых блоков нет в меню «/», окне «Все блоки», «Стиле текста», «Превратить в…» и «Медиа»; Markdown-сокращения для них не срабатывают; вставленная ссылка на видео остаётся ссылкой, если видео нет в наборе.

**Свои наборы** — в `ted.config.php` → `presets` (сервер сам передаёт их в браузер):

```php
'presets' => [
    'news' => ['blocks' => ['h2', 'h3', 'ul', 'ol', 'blockquote', 'image', 'gallery', 'video'], 'mode' => 'edit'],
],
```

`blocks` — `'all'` или список из: `p h2 h3 h4 h5 h6 blockquote pre callout background facts proscons ul ol checklist steps image gallery video audio file table embed iframe columns hr toc accordion tabs button product` (другие имена: `quote`, `code`, `separator`, `bg`). Абзац разрешён всегда. `mode` — `edit`, `view` или `readonly`. Неизвестный блок, ключ или имя набора — понятная ошибка; базовые наборы переопределить нельзя.

**Без PHP** (статичная страница, другая CMS) — те же наборы в браузере:

```js
Ted.init({ selector: '#docs', preset: 'docs' });
Ted.definePreset('news', { blocks: ['h2', 'h3', 'ul', 'image'], mode: 'edit' });
Ted.init({ selector: '#news', preset: 'news' });
Ted.clean(html, { preset: 'text' });                                 // то же для произвольного HTML
```

Прежняя опция `blocks` работает: `blocks: 'mini'` (имя набора), `blocks: 'basic'` (абзац, заголовки, списки, цитата, код, разделитель, чек-лист, шаги) или массив видов. `blocks: 'text'` — без заголовков, как набор `text`.
