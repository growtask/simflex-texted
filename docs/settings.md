# Настройки

[← К оглавлению](README.md)

## Настройки

Все опции необязательны. Передаются в `Ted.init({ … })`.

**Основное**

| Опция | По умолчанию | Описание |
|-------|--------------|----------|
| `selector` / `target` | — | Какие элементы превратить в редактор (`textarea` или `div`) |
| `blocks` | `'all'` | Какие блоки доступны: `'all'`, имя набора (`'mini'`, `'text'`…), `'basic'` или массив типов `['p', 'h2', 'ul']`. Запрещённые убираются из меню, панели и Markdown, а при загрузке, вставке и сохранении становятся текстом |
| `preset` | `null` | Набор: `full`, `mini`, `text`, `readonly`, `docs` или свой (`Ted.definePreset`). В CMS набор и право задаёт сервер — `server` |
| `theme` | `'light'` | Тема интерфейса: `'light'`, `'dark'`, `'auto'` |
| `unit` | `'px'` | `'px'` или `'vw'` — размеры в предпросмотре |
| `placeholder` | — | Подсказка в пустом абзаце |
| `startWithHeading` | `false` | Пустой документ начинается с заголовка |
| `autofocus` | `false` | Поставить курсор в редактор при открытии |
| `value` | — | Начальный HTML (по умолчанию берётся из `textarea` или элемента) |
| `wrap` | `true` | Оборачивать результат в `<div class="ted-content">` |
| `stats` | `true` | Добавлять в обёртку `data-words`, `data-chars`, `data-minutes`, `data-blocks` (для SEO и «времени чтения») |
| `markdown` | `true` | Markdown-сокращения в начале абзаца (`# `, `- `, `1. `, `> `, `---`) |
| `linkBlank` | `true` | Новые ссылки открываются в новой вкладке (`target="_blank" rel="noopener"`) |
| `typograf` | `{}` | Настройки кнопки ✨ «Форматировать текст»: `off`, `protect`, `terms`, `yo` (свои слова с ё), `review`, см. [Форматирование](api.md#форматирование-) |
| `authors` | — | Авторы цитат: массив `[{ id, name, role }]` или функция `(запрос) => массив / Promise` |
| `lang` | `null` | Язык интерфейса: `'ru'`, `'en'` или добавленный через `Ted.addLang`; `null` — выбор пользователя (`localStorage`) или русский, см. [Язык интерфейса](import-export.md#язык-интерфейса) |

**Режим окна** (подробнее — [Режимы встраивания](install.md#режимы-встраивания))

| Опция | По умолчанию | Описание |
|-------|--------------|----------|
| `mode` | `'edit'` | Режим при открытии: `'edit'` или `'view'` |
| `previewMode` | `true` | `false` — режима просмотра нет (админка): в шапке «Сохранить» вместо кнопки просмотра |
| `preview` | `'frame'` | `'frame'` — iframe с экранами 1920 / 1366 / 768 / 414; `'inline'` — просмотр прямо на странице |
| `previewScreen` | `null` | `'editor'` — предпросмотр начинается с ширины колонки редактора |
| `readOnly` | `false` | Только просмотр (для доступов без права редактирования) |
| `dblclickToEdit` | `true` | Двойной клик в просмотре переводит в редактирование |
| `contentCss` | `[]` | CSS сайта для предпросмотра (переменные, шрифты) |
| `pageUrl` | адрес страницы | Публичный адрес страницы для «Копировать ссылку» (строка или `(block) => url`) |
| `toasts` | `true` | Короткие уведомления с «Отменить» |
| `appear` | `true` | `false` — без анимации открытия (панель и блоки появляются по очереди сверху вниз) |

**События и сохранение**

| Опция | Описание |
|-------|----------|
| `onChange(html, editor)` | Любое изменение |
| `onSave(html, editor)` | Сохранение. Должна вернуть `Promise`: «сохранено» только после его успеха |
| `onModeChange(mode, editor)` | Смена режима |
| `autosave` | `true` или строка-ключ: черновик в `localStorage`, восстанавливается после перезагрузки |
| `autosaveDelay` | Пауза в мс перед записью черновика (по умолчанию `800`) |
| `presence` | По умолчанию `true`: один документ в двух вкладках — предупреждение и подтверждение перед сохранением, см. [Один документ в двух вкладках](import-export.md#один-документ-в-двух-вкладках); `false` — выключить |
| `saveAfterUpload` | По умолчанию `true`: после загрузки файла страница сразу сохраняется (`onSave`), см. [Файлы и медиа](files.md); `false` — выключить |

**Файлы и безопасность**

| Опция | Описание |
|-------|----------|
| `mediaSource` | `'direct'` (прямая загрузка, по умолчанию) или `'manager'` (файловый менеджер CMS) |
| `upload` | Функция загрузки для `direct`, обычно `Ted.createUpload(адрес, { headers })` |
| `pickFile` | Функция выбора файла из библиотеки CMS: для `manager`, а при `direct` вместе с `upload` — ссылка «Из библиотеки» в зоне загрузки |
| `mediaPageUrl` | Публичный адрес документа — по нему выбирается каталог для файлов |
| `rawHtml` | `'strict'` (по умолчанию) или `'trusted'` — как поступать со старым «сырым» HTML (таблицы, iframe, формы), см. [Безопасность](security.md#безопасность-прочитайте-обязательно) |

**Данные CMS** (как выглядят блоки — [Блоки](blocks.md))

| Опция | Описание |
|-------|----------|
| `server` | Настройки с сервера: `Config::getClientJson($preset, $canEdit)` → `{ filesUrl, limits, opengraph, iframeHosts, preset, presets, canEdit }`, см. [Установка](install.md) |
| `products` | Каталог для блока «Товар»: `{ search: async (запрос) => [{ id, name, sku, price, oldPrice, image, url }], get: async (id) => товар }` |
| `articles` | Статьи для блока «Встраивание»: `{ search: async (запрос) => [{ id, title, url, text, image, site, date, views, likes }], get: async (id) => статья }` |
| `opengraph` | Карточка по ссылке для «Встраивания»: `async (url) => { url, title, text, image, site }`, обычно `Ted.createOpenGraph(адрес, { headers })`. Если на сервере карточки выключены (`server.opengraph: false`), опция не действует |

## Что хранится в браузере

| Ключ `localStorage` | Что | Когда |
|---------------------|-----|-------|
| `ted-draft:<путь>#<поле>` или свой ключ | черновик текста | при `autosave`; игнорируется, когда на сервере текст уже другой |
| `ted-typograf-off` | выключенные категории ✨ | при переключении в панели проверки |
