# Файлы и медиа

## Загрузка файлов и медиа

Добавление: меню «Медиа», меню `/`, плитки блоков, вставка из буфера, перетаскивание файлов на страницу. Незавершённые загрузки в сохранённый HTML не попадают.
Подпись (text/t3, 13 px) пишется прямо под изображением, видео и аудио (Enter — новый абзац после блока); выбранный блок закрыт светлой маской; у каждого фото галереи своя. Карандаш у изображения и фото открывает окно «Описание (alt)» — такое же, как окно «Якорь».
Фото галереи: ручка ⠿ переносит (и мышью, и Alt + стрелки), карандаш — `alt`, корзина — удалить. Файлы: ручка ⠿ и карандаш (имя файла). Аудио: карандаш — название под волной.

```js
const editor = Ted.create(document.querySelector('textarea'), {
  mediaSource: 'direct',
  mediaPageUrl: '/catalog/product/',
  upload: Ted.createUpload('/admin/products/42/media', { headers: { 'X-CSRF-Token': csrfToken } }),
});
```

- **direct.** `upload(file, { kind, pagePath, signal, onProgress })` возвращает `{ url, name }`; прогресс — число от 0 до 1 или `null`. Поддерживаются отмена и повтор.
- **manager.** Вместо загрузки вызывается `pickFile({ kind, multiple, pagePath, editor })`; верните `{ url, alt?, name? }` или массив.
- **PHP.** Внутри авторизованного маршрута CMS (классы — автозагрузка composer, `Simflex\Texted\…`) после проверки CSRF и прав передайте публичный путь документа в
  `Config::load()->respondToUpload($pagePath, $preset, $canEdit)` (или без файла настроек: `(new MediaStorage('/var/www/site/uf', '/uf'))->respondToUpload($pagePath)` — папка на диске и её адрес). Файлы пишутся в `<папка файлов>/images|video|audio|files/<путь страницы>/`, адрес — `<адрес папки>/…`; изображения конвертируются
  в WebP (качество 82%, длинная сторона не больше 2560 px). **Имя файла берётся из названия загруженного файла и записывается латиницей** (кириллица транслитерируется: «Октябрь 2026 — ТЗ.pdf» → `oktyabr-2026-tz.pdf`); если такое имя уже есть в этой папке, добавляется номер: `oktyabr-2026-tz-2.pdf`. Постер видео называется по видео (`clip-poster.webp`). Ответ содержит `type`, `size`, `originalSize`, `width`, `height`, у видео ещё `poster` — редактор показывает «WebP · 1200×800 · 96 КБ (было 588 КБ, −84%)».
  **Удаление файлов работает и без CMS.** Редактор не удаляет файл сразу (до сохранения Ctrl+Z возвращает блок), а после успешного сохранения сам отправляет на тот же маршрут `action=delete` со списком адресов, которых в документе больше нет (изображения, видео, постеры, аудио, файлы). Маршрут уже обрабатывает `MediaStorage::respondToUpload()`: удаляются только файлы этой страницы из `<папка файлов>/<вид>/<путь страницы>/` с нашими именами — адрес другой папки, другой страницы, вложенной папки или с «..» пропускается (тест `tests/php/test-config.php`). Чтобы не удалить файл, нужный другому документу, передайте третьим аргументом проверку: `$storage->respondToUpload($pagePath, fn (string $url): bool => …)`. Если CMS хочет сравнивать документы сама, есть `$storage->removeUnused($pagePath, $before, $after)`. **После загрузки файла страница сохраняется сама** (вызывается `onSave`; отключить: `saveAfterUpload: false`), поэтому загруженный файл не остаётся на сервере без ссылки. После каждого сохранения история правок (Ctrl+Z) очищается.
- **Форматы и лимиты** (лимиты меняются в `ted.config.php` → `limits`): изображения JPEG/PNG/WebP до 5 МБ (сохраняются как WebP), GIF до 5 МБ (сохраняется как есть, анимация остаётся); видео до 500 МБ: **нужен ffmpeg** (путь — `ted.config.php` → `ffmpeg` или переменная `TED_FFMPEG`; проверка — `php bin/check.php`). С ffmpeg принимаются MP4, WebM, MOV, AVI, MKV, WMV, FLV, MPEG, 3GP: MP4 и WebM сохраняются как есть, остальное становится WebM (VP9 + Opus), постер делает сервер. Без ffmpeg принимаются только MP4, AVI и WebM (AVI сохраняется как есть, браузеры его обычно не проигрывают), остальное отклоняется понятной ошибкой; аудио MP3 и WAV до 50 МБ (без конвертации); файлы PDF/DOCX/XLSX/ZIP до 20 МБ. Лимиты PHP `upload_max_filesize` и `post_max_size` должны быть не меньше.
- **Постер видео.** Первый кадр сохраняется в WebP (ffmpeg на сервере, а без него браузер): `<video poster=… preload="none">` — файл не грузится, пока посетитель не нажмёт play.
- **Файловый менеджер.** `mediaSource: 'manager'` и `pickFile` — только библиотека. **Загрузка и библиотека вместе:** при `mediaSource: 'direct'` передайте и `upload`, и `pickFile` — в зоне загрузки изображения, галереи, видео, аудио и файла появится ссылка «Из библиотеки» («Выбрать изображение или перетащите сюда · Из библиотеки», как Uploader/drop с `library`). Файл из библиотеки не загружается заново и после сохранения не удаляется. Для файлового менеджера SimflexCMS:

  ```js
  pickFile: ({ multiple, extensions }) => window.fileManager.open({ multiple, select: true, accept: extensions || undefined })
    .then((files) => files && files.map((file) => ({ url: file.url, alt: '', name: file.name }))),
  ```

  Демо: `php bin/demo.php` подключает менеджер из `Документы\GitHub\simflex-file-manager` (или `-FileManager <папка>`) — `examples/admin.html?media=direct`; без менеджера — подстановка адреса: `admin.html?media=manager`.
- **Видео по ссылке:** YouTube, Rutube, VK Видео — в пустом блоке видео есть поле «Ссылка…»; при вставке ссылки в текст редактор спрашивает «Вставить видео» или «Оставить ссылку». В редакторе виден настоящий плеер площадки, в HTML остаётся только ссылка `data-ted-video`.
- **Аудиоплеер по макету Media/audio** (play, волна, время, название). В HTML остаётся `<audio controls title="Название">`; на сайте плеер подключает `content.js` (или `Ted.enhance()`, если на сайте загружен `ted.js`), без скрипта работает родной плеер.
- **Скругления.** У изображения, видео и плеера площадки одно скругление — токен сайта `--ted-media-radius` (по умолчанию 24px): `.ted-content { --ted-media-radius: 16px; }`.

**Проверить загрузку на своём компьютере:** выполните `php bin/demo.php` — найдёт PHP, напечатает оценку установки (версия, gd, fileinfo, WebP, настройки `ted.config.php`, лимиты, права на папку файлов), запустит сервер и откроет админку с рабочей загрузкой. Ту же проверку делает `php bin/check.php` на любом сервере (в браузере открывается только с localhost). Демо не для боевого сервера: у него нет авторизации.
