# Изменения texted

Формат: версия — дата — что появилось, что изменилось, что исправлено. Версия в коде — `Ted.version`
(`resources/js/index.js → VERSION`). Номера — по semver: несовместимое изменение (PHP API, настройки, разметка
блоков в сохранённом HTML) — новая старшая версия (2.0.0), новая возможность — 1.x.0, исправление — 1.0.x.
Несовместимые изменения отмечены «⚠».

## 1.0.2 — 25.11.2026 — английский интерфейс целиком, узкое окно

- Английский интерфейс: строки с числами и именами переводятся целиком — `tf('Загружено файлов: {n}', { n })`
  (в словаре ключ с `{n}`), дробные числа и единицы по языку (`2.5 MB` / `2,5 МБ`). Раньше по-русски оставались:
  подпись галереи, кнопки фото и файлов, ход загрузки и итог («WebP · … (было …)»), «Файл больше …», «Не больше N
  строк / столбцов / вкладок», «Статья заменена», «Карточка не получена: …», «Этот сайт нельзя встроить: …», итог ✨,
  сводка просмотра («254 words · 2 min read»), подсказки галереи и видео, кнопки ширин предпросмотра («Desktop, 1920px»).
- Заглушки пустых полей на английском: из блоков («Вопрос», «Заголовок выноски», «Вкладка»…) и нарисованные CSS
  («Шаг», «Подпись», «Пункт», «Выберите язык», «// Вставьте или напишите код», «Имя», «Должность», «Выберите товар»).
  У `.ted-ui` атрибут `lang` стоит с создания редактора, а не только после смены языка в «Ещё».
- Сайт (`content.js`): подписи на языке страницы (`lang="en"` у содержимого или страницы) — «Hide / Show» у
  содержания, «Copy code» у кода, «Tab N» у вкладок без названия, «Video player».
- Окно стало уже (поворот планшета, сужение окна): скрытые кнопки пункта и строки таблицы со старым местом
  раздвигали страницу вбок — теперь уходят к левому краю колонки.
- Документация: убрана ссылка на удалённые `Запустить демо.cmd` и `ЗАПУСК.md`.

## 1.0.1 — 25.11.2026 — исправления по сайту texted

- Тёмная тема опубликованного текста (`[data-ted-theme="dark"] .ted-content`): светлый текст и заголовки, код
  на `main/gray/dark` с тёмной подсветкой, выноска с рамкой, линии, цифры, плюсы и минусы — по макету блоков
  theme=dark. Раньше тёмные цвета текста были только внутри редактора, и на сайте в тёмной теме текст оставался тёмным.
- «Содержание»: полоса прогресса чтения работает и в правке; в правке и в просмотре она прилипает под липкой панелью
  редактора, а не прячется под ней. Редактор ставит на себя `--ted-sticky-top` = шапка сайта + высота своей панели
  (её же учитывает переход по якорям).
- Меню панели редактора («Стиль текста», «Выравнивание», «Цвет», «Ещё» и подменю) прикреплены к окну под панелью:
  при прокрутке страницы не уезжают; не помещаются по высоте — прокручиваются внутри (полоса Scrollbar), страница под
  меню больше не докручивается.
- Просмотр на странице (`preview: 'inline'`): глава «Содержания» и ссылка на раздел (`#якорь`) ведут к заголовку
  в просмотре. Те же id есть в скрытом поле правки — браузер шёл к нему, и страница не прокручивалась.
- Тест демо файлового менеджера пропускается, если пакет `simflex/file-manager` требует ядро Simflex.

## 1.0.0 — 24.11.2026 — первая публичная версия: пакет Simflex (composer, классы `Simflex\Texted`, самодостаточная `dist/`)

- Composer-пакет `simflex/texted` (`composer.json`). Редактор админки Simflex CMS (`simflex/core`) вместо TinyMCE.
- ⚠ Сервер — классы в namespace `Simflex\Texted\` (PSR-4, `src/`), только через автозагрузку composer: файлов `php/*.php`
  и `require` больше нет. Серверная часть блока — класс `Simflex\Texted\Blocks\<Тип>` в папке блока
  (`blocks/<тип>/<Тип>.php`, интерфейс `ServerBlock`) вместо массива функций. Проверка сервера — `bin/check.php`,
  правила папки файлов — `resources/uf.htaccess`, тесты PHP — `tests/php/`.
- ⚠ `dist/` самодостаточна: в ней `ted.js`, `ted.css`, `ted.vw.css`, `content.js` (был в корне пакета), `fonts/`,
  `tiles/`, `icons/` — стили ссылаются на них относительно (`fonts/…`, а не `../fonts/…`). Сайту и CMS достаточно
  опубликовать одну папку `dist/`. Исходники фронтенда — в `resources/`: `js/` (было `src/`), `css/` (было
  `styles/`), `lang/`, `fonts/`, `tiles/`, `icons/`.
- Инструменты разработки — PHP-скрипты в `bin/`, одинаково на Windows, Linux и macOS: `bin/build.php` (одна сборка
  вместо двух), `bin/test.php` (свой `php -S`, Chrome / Chromium / Edge без окна; `--full`, `--suite`, `--only`),
  `bin/demo.php`, `bin/snapshot.php`, `bin/make-preset-vectors.php`. Скрипты PowerShell (`tools/*.ps1`) и папка
  `tools/` удалены; тест загрузки файлов — `tests/php/test-upload.php`; `--full` сверяет `dist/` в git со сборкой.
  Отключённые 19.11 старые наборы (`tests/index.html`, `tests/dist.html`, `tests/walkthrough-all.html`) удалены.
- Правила разработки — в пакете: `AGENTS.md` (структура, команды `bin/`, правила PHP Simflex, Figma 1 в 1,
  безопасность, самопроверка, git), `docs/dev/PRINCIPLES.md` и `docs/dev/LAYOUT.md`. Планы, журналы и отчёты автора —
  в репозитории `simflex-agents` (`plans/texted/`).

### Переход

| Было | Стало |
|---|---|
| `require 'ted/php/config.php'` и другие `require` | `composer require simflex/texted` (автозагрузка) |
| `TedConfig`, `TedSanitizer`, `TedPresets`, `TedBlocks` | `Simflex\Texted\Config`, `Sanitizer`, `Presets`, `Blocks` |
| `TedMediaStorage`, `TedOpenGraph`, `TedRateLimit` | `Simflex\Texted\MediaStorage`, `OpenGraph`, `RateLimit` |
| `TedAccessDenied` | `Simflex\Texted\Exception\AccessDenied` |
| `tedRespondToUpload($storage, $pagePath, $isReferenced)` | `$storage->respondToUpload($pagePath, $isReferenced)` |
| `tedRespondToOpenGraph($enabled)` | `OpenGraph::respondToRequest($isEnabled)` |
| `Config`: `client()`, `clientJson()` | `getClient()`, `getClientJson()` |
| `Config`: `filesDir()`, `filesUrl()`, `limit()`, `limits()`, `ffmpeg()` | `getFilesDir()`, `getFilesUrl()`, `getLimit()`, `getLimits()`, `getFfmpeg()` |
| `Config`: `opengraph()`, `iframeHosts()`, `presets()`, `preset()`, `rate()` | `isOpenGraphEnabled()`, `getIframeHosts()`, `getPresets()`, `getPreset()`, `getRates()` |
| `Config`: `editable()`, `storage()`, `rateLimit()` | `isEditable()`, `createStorage()`, `createRateLimit()` |
| `MediaStorage`: `filesDir()`, `filesUrl()` | `getFilesDir()`, `getFilesUrl()` |
| `OpenGraph`: `allowedUrl()`, `publicIp()`, `pinned()` | `isAllowedUrl()`, `isPublicIp()`, `getPinnedTarget()` |
| `RateLimit::client()` | `RateLimit::getClientKey()` |
| `blocks/<тип>/<тип>.php` (`return ['degrade' => fn …]`), `TedBlocks::hook()` | класс `Blocks\<Тип> implements ServerBlock`, `Blocks::getServerBlock()` |
| `php/check.php`, `php/uf.htaccess` | `bin/check.php`, `resources/uf.htaccess` |
| `content.js` (корень пакета) | `dist/content.js` |
| публикация `dist/`, `fonts/`, `tiles/`, `content.js` | публикация только `dist/` |
| исходники `src/` (JS), `styles/`, `lang/`, `fonts/`, `tiles/`, `icons/` | `resources/js/`, `resources/css/`, `resources/lang/` и т. д. |

`clean()`, `save()`, `respondToUpload()`, `respondToOpenGraph()`, `load()`, `fromArray()` у `Config` — без изменений.

## 0.1.0 — 22.11.2026 — первая версия

**Редактор**
- Блоки: текст, заголовки 2–6, списки, чек-лист, шаги, цитата с автором, выноска, цветной фон, ключевые цифры, плюсы и минусы, код с подсветкой и номерами строк, изображение, галерея, видео, аудио с плеером, файлы, таблица с формулами, колонки, содержание с прогрессом чтения, аккордеон, вкладки, кнопка и баннер, товар, встраивание (статья CMS, карточка по ссылке), iFrame, линия.
- Меню «/», «+», «Все блоки» с миниатюрами; перетаскивание блоков, в том числе внутри и между контейнерами; меню блока («Превратить в…», дублировать, в начало / в конец, якорь, удалить); отмена и повтор.
- Markdown-сокращения в начале строки; вставка из Word, Google Docs, Excel и Markdown-текста; типограф ✨.
- Наборы блоков (`full`, `mini`, `text`, `readonly`, `docs`, свои) и право на правку — проверяются и на сервере, на любой глубине вложения.
- Светлая и тёмная тема, плавная смена; интерфейс на русском и английском; черновик в браузере; предупреждение, если документ открыт в двух вкладках.
- Перенос статей: загрузка и выгрузка Markdown и JSON, промт для нейросети, печать и PDF; старые статьи TinyMCE открываются блоками.
- Клавиатура: Ctrl+. — меню блока, Ctrl+Shift+↑ / ↓ — перенос блока, Esc → Tab — к панели; роли и названия для программ чтения с экрана.

**Сайт**
- Чистый HTML без скриптов в содержимом; поведение вкладок, содержания, аудио, кнопки «Копировать код» — `content.js`; анимации с учётом «уменьшить движение».
- Стили блоков на переменных сайта (дизайн-система Simflex), px и vw.

**Сервер (PHP 8.4+)**
- Очистка HTML по общему с браузером белому списку (`TedSanitizer`), настройки `ted.config.php`, наборы и право на правку.
- Загрузка файлов: тип по содержимому, картинки → WebP с уменьшением, видео → WebM (ffmpeg), лимиты, лимит частоты, удаление только внутри папки файлов; карточки по ссылке с защитой от запросов во внутреннюю сеть.
- Проверка установки — `php php/check.php`.
